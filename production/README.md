# Production outputs

- `gerber.zip` — Gerber, drill, and drill-map files
- `bom.csv` — human-readable bill of materials
- `bom_for_order.csv` — original KiCad-exported BOM for ordering/manufacturing reference
- `designators.csv` — component designators
- `positions.csv` — placement coordinates
- `netlist.ipc` — IPC netlist export

The supplied purchase items are included in both BOM files. The screw size and heat-set insert thread size still need to be selected from the listing variants before ordering.
